# RailSync DSA Engineering Skill

## 1. Purpose

This skill provides the standard workflow for implementing, testing, integrating, explaining, and reviewing DSA algorithms in RailSync.

Use this skill whenever working on:

- algorithm implementation
- algorithm debugging
- algorithm testing
- algorithm optimization
- algorithm visualization data
- algorithm API integration
- algorithm benchmarking
- algorithm trace generation
- algorithm documentation
- DSA viva preparation
